# 灵动资产助手 (AssetFlow) 🚀

> **专业级游戏素材切片与坐标提取工具**
> 
> 一站式处理游戏精灵图 (Spritesheet)、UI 面板、地图切片及各类静态资源。

---

## 🌟 项目简介

**灵动资产助手 (AssetFlow)** 是一款专为游戏开发者设计的轻量级、高性能 Web 工具。它旨在解决游戏开发中“素材定位难、切片效率低”的痛点。通过直观的画布操作，你可以快速标注素材位置、实时预览动画效果，并一键导出项目所需的坐标数据。

## ✨ 核心特性

- 🎯 **智能像素捕捉**：支持自定义网格吸附，确保切片坐标精确到 1 像素，完美适配像素风或高清素材。
- 🎬 **实时动画预览**：框选素材后可直接拖入动作编辑器，实时预览帧动画效果，支持自定义 FPS。
- 📦 **多维数据导出**：
  - **JSON 坐标**：实时生成素材的 X/Y/W/H 坐标字典。
  - **动画配置**：导出包含帧序列关系的动画 JSON。
  - **PNG 序列包**：支持将动作帧自动打包为 ZIP 压缩包下载。
- 🎨 **极致交互体验**：
  - 空格键拖拽画布，滚轮无级缩放。
  - 现代化 UI 设计，支持全中文界面。
  - **防干扰机制**：深度优化浏览器交互，防止拖拽过程中的图片选中蓝光干扰。
- 🛠️ **全能兼容**：不限于精灵图，支持 UI 按钮定位、地图块切分、物件合集管理等。

## 🚀 快速上手

### 环境要求
- 现代浏览器（推荐 Chrome / Edge / Safari）
- 支持 ES6 模块的环境

### 本地运行
由于本项目采用现代化轻量架构（ESM 直接引用），你只需将文件放入任何静态 Web 服务器即可运行：

1. 克隆仓库
2. 在根目录启动静态服务器（例如：`python -m http.server` 或使用 VS Code 的 Live Server）
3. 访问 `index.html`

## 🛠️ 技术栈

- **Core**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Utilities**: [JSZip](https://stuk.github.io/jszip/) (用于打包下载)
- **Deployment**: 静态资源零依赖部署

## 📖 使用指南

1. **导入素材**：点击“导入项目素材”上传你的图片。
2. **设定网格**：在顶部工具栏设置你的基础网格尺寸（如 16x16, 32x32）。
3. **标注资源**：在画布上点击并拖拽即可创建切片区域，右侧面板可实时修改名称。
4. **制作动画**：
   - 切换到“动作预览”选项卡。
   - 创建新动作。
   - 选中左侧已有的切片，点击“追加当前帧”。
5. **获取数据**：切换到“数据面板”，点击“复制到剪贴板”即可获取 JSON 数据。
